# Contributing

Thanks for helping! Bug reports with a failing value and the spreadsheet application that
mis-displays it are especially welcome.

## Development

```sh
npm install
npm test              # unit, property-based, CLI and spreadsheet tests
npm run check         # everything CI runs: typecheck, 100% coverage, build, smoke tests, package lint
```

- The end-to-end spreadsheet tests need LibreOffice (`soffice`) and Python's `openpyxl`
  (`pip install openpyxl`); they are skipped otherwise.
- `npm run test:browser` runs the smoke tests in Chromium (set `CHROMIUM_PATH` to use an installed
  Chromium); `npm run test:bun` runs them in Bun.
- Coverage must stay at 100%. Every behavior change needs a test.

## Locale data

`src/vocabulary.ts` is generated from Unicode CLDR by `scripts/generate-vocabulary.mjs`. The script
merges with the existing file, because CLDR spellings change between releases; run it with every
runtime you have (`node scripts/generate-vocabulary.mjs && bun scripts/generate-vocabulary.mjs`).

`test/fixtures/cp949-whatwg.json` is generated by `scripts/generate-cp949-fixtures.mjs`, which must
run on a WHATWG-conformant runtime such as Bun.
